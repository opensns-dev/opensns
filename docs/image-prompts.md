# Image Prompts for OpenSNS SEO Content

> Generated for 24 pages across Compare, Alternatives, Use Cases, and Blog sections.
> All images should use OpenSNS brand colors (blue/purple gradient) and a clean, modern SaaS aesthetic.
> Target resolution per image type noted in each section.

---

## Naming Convention

```
docs/src/assets/images/{section}/{slug}.{purpose}.png
```

Examples:
- `compare/opensns-vs-adcreative-ai.og.png`
- `blog/why-open-source-ai-marketing.hero.png`
- `use-cases/ai-ads-for-agencies.diagram.png`

---

## Global Style Guide

- **Brand palette**: Deep blue (#1a1a2e) → Purple (#6366f1) → Light blue (#38bdf8) gradient
- **Typography**: Clean sans-serif (Inter or similar), bold white headings
- **Style**: Flat/isometric illustration, NOT photorealistic — modern SaaS marketing aesthetic
- **Composition**: Left-aligned text area + right-aligned visual element (for OG images)
- **Logo**: OpenSNS logo mark in bottom-left or top-left corner
- **Avoid**: Stock photo look, busy backgrounds, more than 3 colors, small unreadable text

## Generation Notes

1. **OG images** (1200x630) are mandatory for social sharing — every page needs one.
2. **In-content images** are optional enhancements — prioritize Use Case diagrams and the feature comparison table.
3. **Priority order**: Blog hero images → VS comparison OG → Use Case diagrams → Alternatives OG → Feature tables.
4. **Competitor logos**: If using actual logos is a trademark concern, use stylized text or generic placeholders.
5. **Format**: PNG for OG images (better quality), WebP for in-content images (smaller size).
6. After generating, add to frontmatter as `hero.image.file` (Starlight) or inline as `![alt](../../assets/images/...)`.
